# Basic HTML Tags

## Aim
To create a simple web page demonstrating the use of basic HTML tags.

## Description
This program demonstrates various HTML elements, including:

- Marquee tag
- Heading tags (H1 to H6)
- Paragraph tag
- Horizontal line and line break
- Blockquote tag
- Preformatted text
- Text formatting tags
- Superscript and subscript
- Emphasis and strong tags
- Mark, small, deleted and inserted text
- Inline code tag

## Technologies Used
- HTML5

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. View the output.
